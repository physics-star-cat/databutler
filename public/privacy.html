🤵 Privacy

Data Butler (databutler.dev) serves verified reference data to AI agents over REST and MCP. This page says plainly what we record when you — or an agent acting for you — use it. The short version: no accounts, no cookies, no stored IP addresses, no logged request bodies.

What we record

  • No accounts. There is nothing to sign up for or log in to; no API keys.
  • No cookies and no browser storage. Pages are static; nothing identifies a returning visitor.
  • Anonymous event counts. Each API or MCP call sends one event to Google Analytics 4 via its server-side Measurement Protocol. An event carries the event name (e.g. agent_mcp_uk_rates_lookup, cite_page_view), a client class derived from the User-Agent header (e.g. claude, cursor, python, browser), the first 100 characters of that User-Agent string, and a random per-request identifier that is never reused. No query parameters, tool arguments, IP address or page URL are included.
  • No IP addresses stored by us. We do not keep server logs. Our hosting provider (Vercel) handles requests and may keep short-lived operational logs under its own privacy policy; we do not export or retain them.
  • No request bodies logged. The question an agent asks (a tax category, a domain, a dataset of numbers for a statistics tool, a vehicle) is processed to answer it and then discarded.

Third-party fetches made on your behalf

Some tools compute their answer live by fetching public sources. In those cases the value you asked about travels to that source, together with our User-Agent (databutler.dev-provenance/1.0 or databutler-hub/1.0); your IP address does not, because the request originates from our server.

Everything else (UK rates, exams, statistics, French and Japanese recall datasets) is answered from data on our server with no external call.

Citation pages

Every answer carries a cite.url permalink such as /r/uk/rates?category=income-tax. These pages are stateless: the URL encodes the query and re-runs it. Opening one records a single anonymous cite_page_view event as above. They are marked noindex.
