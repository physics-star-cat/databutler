How a figure is verified

Every figure is one record at one URL. The record holds the value, the official page it was read from, and the date a person read it there. Nothing is copied from memory, a news story or another site.

The record's hash is its fingerprint: SHA-256 over the record in canonical JSON, so the same record always gives the same hash and any edit changes it. The hash is also the page's ETag, so a client that already holds a figure asks "has this changed?" in one request and gets 304 when it has not. The whole collection has a digest in /.well-known/facts.json; store it, and re-read only when it moves.

The signature is Ed25519 over the hash, made with Data Butler's published key (/.well-known/jwks.json). It proves a record came from here and was not altered on the way, wherever it was cached or quoted.

Freshness is checked, not assumed. Every Monday a watcher re-fetches every official page. A figure whose page changed, whose scheduled change date has passed, or whose verification is older than you asked for (?max_age=30d) is marked stale with the reason, until a person re-verifies it against the live page. Corrections are appended to the record, never edited away.

This is an open convention, Verified Facts v0.3, and any site can publish figures the same way: a static JSON file is enough, signing is optional, and npx verified-facts check your-site says whether it conforms (how to publish · who does).
